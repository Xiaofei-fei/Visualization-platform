统一交通分析平台

风险态势、公交线路和线网优化共用一个项目。当前数据来自原仓库的历史示例，适合回放、对比与研究。

正在读取本地数据概况…

风险态势

异常风险排名、指标雷达、事件解析与已有动态图片。保留 1.0、2.0 两个数据版本。

原始公交

按线路及上下行方向查询高德公交线路，查看原始指标。

优化线网

切换原始和优化线路，比较路线与优化前后的指标。

历史路网

按历史事件编号查询关联路段、事故位置与时间。

启用地图

将项目中的 config.local.example.js 复制为 public/config.local.js，填写自己的高德 Web Key 与安全配置，再刷新业务页面。地图和在线公交查询需要联网及有效授权。

数据版本、图片编号及迁移细节见项目 README 与 docs/MIGRATION.md。
