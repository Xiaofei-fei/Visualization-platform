# 统一交通风险、公交查询和线网优化项目

三个原仓库重复维护路网、样式和风险分析，同时分别包含不同版本的指标数据、动态图片、公交及优化功能。本次在 Visualization-platform 的独立整合分支中提供一个可运行的静态项目，统一配置、导航和资源，保留四个业务模块与两版风险指标。

完整保留三个仓库的原始提交历史。重复资源按内容复用，未使用的旧SDK快照、模板、供应商库和8个旧数据/图片/SCSS文件从运行目录移除；159项源文件均有SHA256迁移记录或原始commit/path恢复位置。GitHub及高德实际凭证不进入Git。

修复首次风险选择、图表复用、空值和搜索、历史编号校验、异步公交响应覆盖、开关状态和SDK加载时序等问题。风险页在地图SDK加载前启用WebGL，避免SVG降级造成Loca初始化异常。

验证：9项Node检查、16项浏览器集成测试；另使用真实高德SDK加载四个页面，并在原始公交和优化页实际查询130路，两处均返回OK、绘制匹配线路。不同部署域名、硬件GPU、全部历史公交、Docker和GitHub Actions需按各自环境验收。

默认分支保持原样，部署产物为dist/，不包含自动生产部署。合入时请选择merge commit以保留三个源仓库的历史。
