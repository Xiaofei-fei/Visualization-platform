# 统一交通可视化项目设计

依据用户授权实施整合，保留原仓库、默认分支与全部 Git 历史。目标为一个可部署的静态站点，统一配置、导航、资源目录和测试，同时保留风险排名/雷达/异常解析/动态图片、原始公交上下行、优化路线/指标、历史路网编号查询。

选择：保留现有 Vue 1.0.26 与 ECharts 4 的页面行为，抽离脚本和共用启动器；以 Roadnetrisk2.0 为基线，在新分支合入另外两个完整历史。无需引入新框架或后端。三个独立应用简单打包不能去重；完全重写会增加业务回归风险，因此均未采用。

风险页面采用同一份代码，保留 v1/v2 数据选择。审计发现两个版本的拥堵指标确有差异，不能用空白规范化覆盖。公交页保留 SDK 1.4.15，风险页使用 SDK 2.0 + Loca 2.0.0；页面间完整导航，避免两个 SDK 全局冲突。Loca 兼容性依据 https://lbs.amap.com/api/loca-v2/intro 。

同内容资源只保留一份；同名不同内容保留明确版本。所有原始文件均记录 SHA256、迁移去向或历史取回路径；旧供应商 SDK 快照及未使用模板只留 Git 历史。所有原数据保留，不编造后端、实时数据或动态图片对应关系。

配置通过 config.js 和未跟踪的 config.local.js，支持 AMAP_KEY、securityJsCode 或 serviceHost；加载失败显示可恢复提示，不能白屏。地图/实时公交依赖用户有效高德凭证与网络。无凭证时首页仍可查看离线数据概况和运行指引；不声称地图可离线使用。

验证：本地静态资源与子路径部署，真实 Vue/ECharts + 拦截外部高德边界的浏览器集成测试，含首选风险项、数据版本差异、图片存在/缺失、路网非法输入、公交查询及优化开关。外部授权/瓦片/实时公交不由桩测试证明，单独记为未验证。无需破坏现有默认分支即可交付可克隆 Git bundle 和源代码包；如 Git 推送可用，创建草稿 PR。
